## 📌 Overview

A clean **Text Counter** web app that instantly counts characters, words, sentences, paragraphs, and spaces in real time.

---

## ✨ Key Features

- Real-time counting  
- Words, characters, sentences  
- Copy text button  
- Clear all button  
- Keyboard shortcuts  
- Minimal interface
